## Kreyòl

Yon **Agent Skill** open source ki aprann asistan AI yo ekri, korije ak tradui **Kreyòl ayisyen** kòrèkteman, ak òtograf ofisyèl la.

Li mache ak Claude ak lòt zouti ki sipòte estanda ouvè [Agent Skills](https://agentskills.io) la.

### Kisa li fè

- Ekri Kreyòl ak òtograf ofisyèl la (`mwen`, pa `moin`)
- Evite melanj ak fransè
- Eksplike gramè: atik (la, a, an, nan), mak tan (te, ap, pral), pwonon
- Korije tèks ak respè pou fason chak moun pale
- Tradui sans la, pa mo pou mo
- Pwovèb ak sans yo
- Avètisman otomatik pou tèks sou sante ak lalwa

### Kijan pou enstale l

- **Claude (claude.ai):**
  1. Telechaje fichye `kreyol-ayisyen.zip` la nan paj [Releases](https://github.com/SteveJ509/kreyol-ayisyen-skill/releases/latest) la. Pa dekonprese l.
  2. Nan Claude, ale nan **Customize → Skills** ([claude.ai/customize](https://claude.ai/customize)).
  3. Klike **+**, apre sa **+ Create skill**, epi **Upload a skill**.
  4. Chwazi fichye ZIP la, epi asire w skill la aktive.
- **Claude Code ak lòt zouti:** Kopye dosye `skills/kreyol-ayisyen` la nan dosye skills zouti w la (pa egzanp `~/.claude/skills/`).

### Kontribye

Pwojè sa a se pou kominote a. Ou ka ede:
- Korije erè òtograf oswa gramè
- Ajoute mo, ekspresyon ak pwovèb
- Ajoute diferans pa rejyon (Nò, Sid, Lwès...)

Ou pa bezwen konn pwogramasyon pou w ede. Li [gid kontribisyon an](CONTRIBUTING.md), oswa louvri yon [Issue](https://github.com/SteveJ509/kreyol-ayisyen-skill/issues/new/choose) dirèkteman. Men anpil, chay pa lou! 🤝

### ⚠️ Avètisman

Zouti sa a la sèlman pou ede kominikasyon. Li pa ranplase yon tradiktè sètifye, yon entèprèt medikal, yon doktè oswa yon avoka.

## English

An open-source **Agent Skill** that teaches AI assistants to write, correct and translate **Haitian Creole** accurately, using the official orthography.

Works with Claude and any tool that supports the open [Agent Skills](https://agentskills.io) standard.

### Features

- Official orthography (IPN 1979), avoiding French-based spellings
- Grammar guidance: postposed determiners, tense/aspect markers, pronouns
- Respectful text correction that preserves regional voice
- Meaning-based translation
- Proverbs with explanations
- Automatic disclaimer for health and legal content

### Contributing

No coding needed. See [CONTRIBUTING.md](CONTRIBUTING.md) or [open an issue](https://github.com/SteveJ509/kreyol-ayisyen-skill/issues/new/choose).

### Disclaimer

This tool supports communication only. It does not replace a certified translator, medical interpreter, doctor or lawyer.
